# raw_models/

Drop zone for **uncompressed** GLB downloads (Sketchfab CC0 etc.) before they
enter the Phase A asset pipeline. Files in this directory are **gitignored**
because raw Sketchfab models are typically 50–200 MB each.

## Workflow

1. **Download** a CC0-licensed GLB from Sketchfab (or another asset source —
   verify the license, prefer CC0 over CC-BY when an attribution file would be
   inconvenient).
2. **Rename** to match the catalog id: `f_bed_003.glb`, `f_chair_002.glb`, …
   See `src/backend/src/main/resources/db/migration/V9__seed_curated_assets.sql`
   for the full id list (28 rows across `bed`, `chair`, `desk`, `lighting`).
3. **Compress** to mobile-friendly size:
   ```
   ./scripts/compress-glb.sh raw_models/f_bed_003.glb
   ```
   Produces `raw_models/f_bed_003.compressed.glb`. Verify the rendered model
   in a glTF viewer (e.g. https://gltf-viewer.donmccurdy.com) before shipping.
4. **Render a JPG preview** of the model from a clean angle (Sketchfab's
   thumbnail is fine; otherwise Blender, Three.js Editor, or any glTF
   viewer's screenshot).
5. **Move into place** — drop both files into the static serving dir under
   the catalog id:
   ```
   mv raw_models/f_bed_003.compressed.glb  src/backend/var/static/furniture/f_bed_003.glb
   mv raw_models/f_bed_003.jpg             src/backend/var/static/furniture/f_bed_003.jpg
   ```
6. **No DB change needed** — V9 already points every row at
   `/static/furniture/<id>.{jpg,glb}`. Restart the backend (or hit a fresh
   `/recommendations` call) and the new asset is live.

## Phase A asset health

Until a real asset replaces a row, the placeholder you'll see is:

- **JPG** — a labelled card with the row's color swatch + dimensions
  (auto-generated by `scripts/seed_placeholder_assets.py`-equivalent inline
   block in the Phase A slice).
- **GLB** — the empty type-matched stub from `src/mobile/assets/ar/models/`.
  Loads in `<model-viewer>` without error, renders nothing visible. This is
  intentional: it confirms the per-row plumbing works while you swap models
  in one at a time.

## What NOT to commit

- Anything inside `raw_models/` (covered by `.gitignore`)
- Any GLB > 20 MB anywhere in the repo (use the compression script first)
